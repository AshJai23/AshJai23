How this version works

This page sends JSON to the FastAPI process serving it. Python runs on your local server, not through Pyodide. Keep the default 127.0.0.1 binding. No scan database, arbitrary URL fetching or firm lookup is implemented.

Scam checks use deterministic rules. The separate Ridge price model uses purged chronological train/calibration/test splits and reports an unchanged-price baseline. The model may lose to that baseline.
